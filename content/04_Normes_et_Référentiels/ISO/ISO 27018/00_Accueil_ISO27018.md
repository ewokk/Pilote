# Accueil du cours ISO/IEC 27018

Bienvenue dans ce module consacré à **l’ISO/IEC 27018**, centré sur la **protection des données personnelles (PII)** dans les environnements Cloud. Ce cours vous aidera à comprendre comment renforcer la confidentialité dans un contexte dématérialisé.

> [!info]
> **Public cible** : RSSI, consultants, auditeurs, décideurs IT
