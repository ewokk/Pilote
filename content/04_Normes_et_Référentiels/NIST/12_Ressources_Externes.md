# 12. Ressources externes recommandées pour le NIST CSF

## Objectif du chapitre

Ce chapitre présente les **ressources officielles et communautaires** utiles pour mettre en œuvre le NIST CSF dans la durée : documents, outils, plateformes, guides et communautés.

---

## 1. Documents officiels NIST

| Document | Description |
|---------|-------------|
| **CSF 2.0 Core** | Noyau du framework avec catégories, sous-catégories et fonctions |
| **CSF 2.0 Reference Tool** | Fichier JSON officiel pour intégrer le CSF dans des outils |
| **Implementation Examples** | Exemples concrets d’implémentation par sous-catégorie |
| **Profiles Library** | Bibliothèque de profils sectoriels (finance, énergie, santé…) |

👉 Disponibles sur : https://www.nist.gov/cyberframework

---

## Synthèse opérationnelle

| Ressource | Utilisation clé |
|-----------|-----------------|
| NIST.gov | Documentation officielle complète |
| GitHub / JSON | Intégration du CSF dans outils GRC |
| SP 800-* | Guides spécialisés (contrôles, incidents, tests) |
| Outils open source | Déploiement opérationnel sans licence |
| Plateformes d’échange | Partage d’indicateurs et retours d’expérience |
