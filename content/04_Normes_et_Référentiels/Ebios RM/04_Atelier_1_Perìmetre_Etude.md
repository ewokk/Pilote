# Atelier 1 – Définir le périmètre de l’étude

## Objectif

Identifier ce qu’il faut protéger :
- **Les valeurs métier** critiques pour l'organisation ;
- **Les événements redoutés** susceptibles de nuire à ces valeurs ;
- Les **biens supports** permettant leur fonctionnement.

## Étapes de l’atelier

1. Identifier les **valeurs métier**
2. Identifier les **événements redoutés**
3. Identifier les **biens supports**
4. Évaluer la **gravité** des événements

## Outils et représentations

| Élément | Exemple |
|--------|---------|
| Valeur métier | Données clients, continuité de service, image de marque |
| Événement redouté | Fuite de données, indisponibilité d’un service |
| Bien support | Serveur, application, base de données |

### Matrice Gravité

La gravité peut être cotée selon plusieurs critères :
- Impact financier
- Atteinte à l’image
- Conséquences réglementaires

> [!example]  
> Une indisponibilité de 4h du site e-commerce peut avoir une gravité **majeure** si elle survient durant un pic de vente.

## Livrables attendus

- Liste des valeurs métier
- Tableau des événements redoutés
- Liste des biens supports associés
- Cotation de la gravité

> [!tip]  
> Utilise des ateliers collaboratifs avec les métiers pour identifier les véritables **valeurs métier**, souvent ignorées dans les approches techniques.
