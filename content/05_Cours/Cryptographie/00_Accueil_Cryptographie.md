# Accueil – Cours Cryptographie

Bienvenue dans ce module de cryptographie appliquée à la SSI. Vous y découvrirez les bases théoriques, les algorithmes classiques et modernes, les usages opérationnels (VPN, S/MIME, stockage) et les attaques connues. Ce cours est conçu pour les professionnels souhaitant sécuriser les échanges et les données.

> [!info]
> **Public cible** : RSSI, consultants, administrateurs, juristes IT
