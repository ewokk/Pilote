# Cas pratique : PCA / PRA pour une PME de services informatiques

## Contexte
- PME de 35 personnes
- Un site principal
- 3 applications critiques : CRM, facturation, portail client

## PCA simplifié
- Télétravail prévu pour 100% du personnel
- Sauvegardes quotidiennes externalisées
- PC portables fournis
- Cellule de crise activable via Teams

## PRA simplifié
- Serveurs redondés en cloud OVH
- Bascule automatique en 2 heures
- Tests de restauration chaque trimestre
- Priorité de reprise : facturation > CRM > portail

## Leçons
- Importance d’avoir une documentation synthétique
- Une cellule de crise pré-entraînée fait gagner un temps précieux
