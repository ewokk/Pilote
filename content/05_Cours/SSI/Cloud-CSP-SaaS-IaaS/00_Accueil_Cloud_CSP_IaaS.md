# Accueil — Modèles Cloud : CSP, IaaS, PaaS, SaaS

Bienvenue dans ce module sur les modèles Cloud et la sécurité associée. Vous y découvrirez les différences entre IaaS, PaaS, SaaS, la notion de responsabilité partagée et les risques spécifiques aux environnements Cloud. Il est conçu pour les architectes, les administrateurs Cloud et les responsables sécurité.
