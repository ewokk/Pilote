# Typologies de veilles SSI

## Veille technique

| Type                | Exemple                                              |
|---------------------|------------------------------------------------------|
| Vulnérabilités       | CVE, bulletins CERT-FR, GitHub advisory             |
| Exploits publics     | Proof of Concept (PoC), Metasploit, CISA KEV        |
| Produits utilisés    | VMware, Fortinet, Exchange, Java, M365…             |

---

## Veille réglementaire

| Référentiel        | Exemple                                      |
|--------------------|----------------------------------------------|
| Données personnelles | CNIL, EDPB, RGPD, jurisprudences            |
| Normes SSI          | ISO 27001, NIS2, DORA, LPM                   |
| Obligations métiers | PCI-DSS, HDS, ENS espagnol, etc.             |

---

## Veille stratégique et géopolitique

- Activité d’acteurs malveillants (APT, hacktivisme, ransomware groups…)
- Campagnes de désinformation
- Conflits et cyberattaques étatiques

---

## Veille sectorielle / métier

- Banque, santé, éducation, industrie
- Contextualisation des menaces par secteur

> [!tip]
> Ne pas mélanger toutes les veilles : **adapter le type à la cible** (SOC ≠ DG ≠ DPO).
