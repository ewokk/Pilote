# Organisation, fréquence et canaux de diffusion de la veille

## Structuration d’un processus de diffusion

| Élément           | Possibilités                                      |
|-------------------|---------------------------------------------------|
| Fréquence         | Quotidien / Hebdo / Mensuel / Temps réel          |
| Ciblage           | RSSI, DSI, SOC, CODIR, dev, DPO…                  |
| Canal             | Mail, Slack, Obsidian, intranet, dashboard CTI   |
| Format            | Markdown, HTML, slides, tableau, résumé 5 lignes |

---

## Bonnes pratiques

- Ne pas noyer l’audience sous les alertes
- Adapter le **format au public** :
  - Dev : PoC technique, patch
  - CODIR : impact métier, risque, budget
- Centraliser dans un **point unique** : `veille.md`, canal , mailing-list

---

## Exemples de fréquence

| Type de veille     | Fréquence typique    |
|--------------------|----------------------|
| Vuln. critique     | Temps réel / quotidien |
| Patch produit      | Hebdomadaire         |
| Juridique RGPD     | Mensuel              |
| APT / géopolitique | Hebdo / mensuel      |
