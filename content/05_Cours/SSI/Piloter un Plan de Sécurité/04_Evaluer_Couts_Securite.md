# Évaluer les coûts d’un chantier sécurité

## Types de coûts à anticiper

| Type                | Exemple                             |
|---------------------|-------------------------------------|
| Logiciel            | Licence annuelle SIEM               |
| Matériel            | Firewall, NAS, token hardware       |
| Intégration         | ESN, prestation cybersécurité       |
| Formation           | Admins, utilisateurs                |
| Maintien            | Renouvellement, support, tests      |
| Temps humain        | Jours-hommes internes               |

---

## Coût total de possession (TCO)

- **Coût initial** : achat, intégration
- **Coût récurrent** : support, licences
- **Coût indirect** : dépendance fournisseur, charge admin
