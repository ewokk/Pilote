# Outils d’agrégation et d’automatisation de veille

## Agrégateurs RSS

| Outil             | Caractéristiques                                |
|-------------------|--------------------------------------------------|
| Feedly            | SaaS, ergonomique, IA intégrée (Feedly Leo)     |
| Fluent Reader     | Gratuit, local, multiplateforme                 |
| RSS Owl / QuiteRSS| Légers, simples                                 |

---

## Plateformes CTI collaboratives

| Outil      | Objectif principal                      |
|------------|------------------------------------------|
| MISP       | Partage d’IOC, corrélation STIX/TAXII   |
| OpenCTI    | Veille enrichie, pivot avec ATT&CK      |
| TheHive    | Réponse à incident + observables        |

## Veille sociale & communautaire

- X / Twitter Lists
- GitHub Notifications (watch, star, release)
- Reddit /r/netsec
- HackerOne / Bugcrowd public disclosures

---

## Automatisation inter-outils

- Zapier / Make
- IFTTT
- Huginn (open source + programmable)
- Node-RED

> [!tip]
> Combine les outils : par exemple, **Feedly + Huginn + GitHub + Obsidian** = veille continue multi-source.
