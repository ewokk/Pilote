# Typologie des audits en cybersécurité

## Audits internes

- Réalisés **par l’organisation elle-même**
- Objectifs :
  - Évaluer le niveau de conformité
  - Préparer une certification
  - Identifier des axes d’amélioration
- Avantage : souplesse, pédagogie
- Inconvénient : **risque de biais**

---

## Audits externes

- Réalisés par un **tiers indépendant** (cabinet, prestataire)
- Objectifs :
  - Audit de certification (ISO, PCI-DSS…)
  - Due diligence fournisseur
  - Audit contractuel client
- Avantage : objectivité, crédibilité
- Inconvénient : coût, rigidité

---

## Audits techniques spécifiques

- Audit de configuration (AD, réseau, pare-feu…)
- Audit de code / revue de permissions
- Audit de conformité des logs / traçabilité
- Test d’intrusion (pentest) — à ne pas confondre avec un audit global

> [!tip]
> La complémentarité entre **audit organisationnel** et **audit technique** est essentielle.
