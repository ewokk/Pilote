# S’outiller Avec un logiciel de GRC SSI

## GRC = Governance, Risk, Compliance

- Plateforme intégrée pour :
  - Piloter les risques
  - Gérer les politiques et audits
  - Suivre les contrôles
  - Consolider la conformité multi-référentiels

---

## Outils GRC populaires

| Outil              | Positionnement                              |
|--------------------|---------------------------------------------|
| OneTrust           | RGPD, gouvernance données, cartographie     |
| Varonis            | GRC + IAM orienté fichiers / droits         |
| EzRisk / Risk’n Tic| GRC SSI Français                            |
| 6clics, LogicGate  | Plateformes internationales modulaires       |
| Excel              | Oui, toujours valable dans les petites structures |

---

## Clés d’un bon déploiement GRC

- Définir les objectifs (conformité, pilotage, audit ?)
- Ne pas tout vouloir digitaliser d’un coup
- **Structurer les référentiels en amont**
- Former les équipes à la saisie / maintenance

> [!success]
> Un bon GRC est un **référentiel vivant**, pas un tableur figé.
