# Guide d’application pratique – Modèles et outils

Ce guide fournit les ressources nécessaires pour transformer le cours en **plans concrets de PCA et de PRA**. Ces modèles sont prêts à être personnalisés pour une mise en œuvre rapide.

## 📄 Modèles fournis

| Fichier | Description |
|--------|-------------|
| `MODELE_BIA.xlsx` | Modèle Excel d’analyse d’impact métier |
| `MODELE_PCA.md` | Squelette PCA à remplir (plan complet) |
| `MODELE_PRA.md` | Squelette PRA (ordre de reprise, systèmes, tests) |
| `CHECKLIST_Activation_Crise.md` | Fiche réflexe d’activation d’une cellule de crise |
| `CAS_PCA-PRA_PME.md` | Cas complet pour une PME (exploitation immédiate) |

## 🔧 Conseils de mise en œuvre

- **Personnaliser les trames** selon vos processus, structures, exigences réglementaires
- **Tester chaque plan** une fois rédigé, au moins une fois par an
- **Archiver** toute version validée et historiser les mises à jour
- **Diffuser** les versions finales aux acteurs concernés : IT, RH, métiers, juridique…

> [!tip]
> Un PCA ou PRA qui dort dans un tiroir est un risque. Un plan documenté, testé, partagé, et maintenu, devient une vraie arme de résilience.
