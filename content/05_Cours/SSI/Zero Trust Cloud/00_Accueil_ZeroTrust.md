# Accueil — Zero Trust Cloud

Bienvenue dans ce module consacré à l’approche Zero Trust appliquée aux environnements Cloud. Vous y découvrirez les principes fondamentaux du modèle, les architectures techniques associées et les bonnes pratiques de sécurisation. Ce cours fournit un cadre opérationnel pour implémenter la segmentation, le contrôle d'accès, la supervision et l'automatisation dans un contexte Zero Trust.

> [!info]
> **Public cible** : RSSI, analystes, architectes SSI, consultants
