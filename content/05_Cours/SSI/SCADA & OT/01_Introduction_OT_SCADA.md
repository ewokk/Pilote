# Introduction aux environnements OT et SCADA

## OT — Operational Technology

L’**OT** regroupe l’ensemble des systèmes qui pilotent les équipements physiques d’une industrie :
- capteurs, actionneurs
- automates programmables (PLC)
- interfaces opérateurs (HMI)
- réseaux industriels et supervision

---

## SCADA — Supervisory Control And Data Acquisition

Le SCADA est le système de **supervision centralisée** d’un environnement industriel :
- collecte de données (température, pression…)
- contrôle à distance (marche/arrêt, alarmes)
- visualisation graphique (synoptique)

> [!example]
> Un SCADA dans une usine de traitement d’eau gère :
> - la pression des pompes
> - les alertes chimiques
> - le démarrage automatique des vannes

---

## Autres termes clés

| Terme | Description |
|-------|-------------|
| ICS   | Industrial Control System = ensemble OT (SCADA, DCS, PLC…) |
| DCS   | Distributed Control System (plus localisé que SCADA) |
| RTU   | Remote Terminal Unit, périphérique de collecte à distance |
| HMI   | Human-Machine Interface (tableau de contrôle opérateur) |
| PLC   | Automate programmable (logiciel embarqué, temps réel) |
