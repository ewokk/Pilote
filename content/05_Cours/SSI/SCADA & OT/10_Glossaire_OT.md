# Glossaire OT

| Terme        | Définition courte |
|--------------|--------------------|
| SCADA        | Supervision des systèmes industriels |
| PLC          | Automate programmable |
| DCS          | Système de contrôle distribué |
| HMI          | Interface Homme-Machine |
| ICS          | Ensemble des composants OT |
| RTU          | Unité distante de télégestion |
| Modbus       | Protocole non sécurisé de communication |
| OPC UA       | Protocole sécurisé d’interopérabilité |
| Purdue Model | Modèle de segmentation réseau OT |
| DMZ          | Zone tampon entre IT et OT |
| Jumpbox      | Serveur pivot pour accès sécurisé |
| MFA          | Authentification multifacteur |
| Bastion      | Serveur sécurisé pour accès distant |
| Diode        | Matériel filtrant à sens unique |
| Whitelisting | Autorisation explicite d’exécution |
