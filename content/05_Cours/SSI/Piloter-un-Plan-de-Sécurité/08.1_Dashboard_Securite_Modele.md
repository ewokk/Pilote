# Modèle de tableau de bord sécurité

## Structure du tableau de bord

| Indicateur                | Objectif | Valeur cible | Valeur actuelle | Tendance |
| ------------------------- | -------- | ------------ | --------------- | -------- |
| Postes à jour             | 100 %    | 95 %         | up              |          |
| MFA déployé               | 100 %    | 100 %        | ✓               |          |
| Phishing simulation échec | < 5 %    | 12 %         | down            |          |
| Incidents avec impact     | 0        | 1            | down            |          |

---

## Types de visualisation possibles

- Camemberts (répartition)
- Barres (évolution)
- Jauges (atteinte d’un objectif)
- Feu tricolore (RAG : Rouge/Orange/Vert)

---

## Outils possibles

- Excel / Google Sheets
- Obsidian (Dataview, Templater)
- Power BI
- Tableaux de bord GRC / RSSI
